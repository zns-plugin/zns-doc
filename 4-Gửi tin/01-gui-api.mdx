# <p align="center">Gửi tin qua API</p>

Quý khách có 2 cách gửi Tin nhắn ZBS Template: **gửi qua API** hoặc **gửi theo chiến dịch** (không cần API). Bài này hướng dẫn luồng gửi tin qua API, từ lấy Access Token đến nhận sự kiện khi người dùng nhận được tin.

## Luồng gửi tin qua API

### Bước 1 · Lấy Access Token

Access Token là mã định danh để Ứng dụng (AppID) gửi tin thay mặt OA. Quý khách lấy Access Token theo 1 trong 2 cách:

- **Công cụ API Explorer:** dành cho Admin của OA hoặc Ứng dụng. Xem hướng dẫn tại [Uỷ quyền Ứng dụng (AppID) cho OA](https://zalo.solutions/business-message/guidelines/huong-dan-uy-quyen-oa-cho-ung-dung-appid).
- **Giao thức OAuth:** dành cho người có kiến thức lập trình, hoặc khi doanh nghiệp dùng Ứng dụng của bên thứ 3. Xem tại [Xác thực và uỷ quyền cho Ứng dụng](https://developers.zalo.me/docs/official-account/bat-dau/xac-thuc-va-uy-quyen-cho-ung-dung-new).

<blockquote style={{ margin: "16px 0", padding: "14px 16px", borderRadius: "12px", background: "#EEF5FF", border: "1px solid #CFE0FF", fontStyle: "normal", quotes: "none" }}><p style={{ margin: "0" }}><strong>Lưu ý:</strong> Access Token có hiệu lực 25 giờ. Khi hết hạn, Quý khách dùng Refresh Token (hiệu lực 3 tháng) để tạo lại Access Token mới.</p></blockquote>

### Bước 2 · Gửi request API

Gửi request `POST` đến `https://business.openapi.zalo.me/message/template`, kèm `access_token` ở header và các thông tin sau ở body:

### Bước 3 · Nhận phản hồi (response)

Sau khi request được gửi đi, máy chủ Zalo phản hồi với các thông tin sau:

Chỉ trả về nếu request thành công</td></tr><tr><td style={{ padding: "10px 12px", borderBottom: "1px solid #E3E9F2", verticalAlign: "top" }}>`sent_time`</td><td style={{ padding: "10px 12px", borderBottom: "1px solid #E3E9F2", verticalAlign: "top" }}>Thời gian máy chủ Zalo bắt đầu gửi tin (định dạng timestamp)</td></tr><tr><td style={{ padding: "10px 12px", borderBottom: "1px solid #E3E9F2", verticalAlign: "top" }}>`quota`</td><td style={{ padding: "10px 12px", borderBottom: "1px solid #E3E9F2", verticalAlign: "top" }}>Thông tin hạn mức gửi tin của OA: `dailyQuota` là số tin được gửi trong ngày, `remainingQuota` là số tin còn lại trong ngày. Chỉ trả về nếu request thành công</td></tr></tbody></table></div>

**Ví dụ response:**

```json
{
  "error": 0,
  "message": "Success",
  "data": {
    "msg_id": "a4d0243feee163bd3af2",
    "sent_time": "1626926349402",
    "quota": {
      "dailyQuota": "500",
      "remainingQuota": "499"
    }
  }
}
```

### Bước 4 · Theo dõi sự kiện gửi tin

Nếu request thành công, tin sẽ được gửi tới người dùng:

- `sent_time`: thời điểm máy chủ Zalo bắt đầu gửi tin.
- `delivery_time`: thời điểm người dùng nhận được tin trên thiết bị.

### Bước 5 · Nhận sự kiện người dùng nhận được tin

Khi tin đến thiết bị của người dùng, hệ thống gửi sự kiện `user_received_message` tới Webhook URL của Ứng dụng với các thông tin:
